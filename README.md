# Blocky Pet Hatchery

Готовый Roblox-скрипт: создаёт яйцемат и семь милых кубических животных без сторонних моделей и asset ID.

## Установка

1. Откройте игру в Roblox Studio. Включите **View → Explorer**.
2. Создайте обычный **Script** в **ServerScriptService**, удалите его содержимое и вставьте весь код из `AnimalHatchery.server.lua`.
3. Нажмите **Play**. Яйцемат появится рядом с первым SpawnLocation (если его нет — около координат 0, 0, 0). Подойдите и удерживайте **E** или кнопку взаимодействия на телефоне/геймпаде.

Открытие бесплатное. Яйцемат занят на время анимации, поэтому другие игроки могут открыть яйцо после завершения. Выпавший питомец следует за игроком и заменяет предыдущего; питомцы не сохраняются между сессиями. Ледяные питомцы создают кристаллы, лавовый дракончик — вулканы, у всех есть вспышка и частицы. Результат выбирается на сервере.

## Настройка

В начале скрипта таблица `pets`: `weight` задаёт относительный вес выпадения (сейчас сумма весов 100), цвета и внешний вид. Позиция яйцемата вычисляется в разделе `Put the station near the spawn`; измените `center`, если нужно поставить его в другом месте. Эффекты временные и удаляются после открытия.
